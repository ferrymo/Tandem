# Tandem

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

面向同时推进多个团队和项目的指挥官及参与协作的成员。成员在本人账号和项目授权范围内工作；指挥官决定目标、范围与关键对外操作。

## Product Purpose

人与 AI Agent 共同规划、执行和交付。默认 T 组由产品设计师、技术架构师、研发工程师组成，系统承担阶段编排；人负责方向与关键决策。产品以运行、版本、回执和交付证据呈现进展。

## Capabilities and Constraints

产品、架构及体验分别以 [01 产品设计](../../docs/01-产品设计文档.md)、[02 技术架构](../../docs/02-技术架构文档.md)、[03 设计规范](../../docs/03-设计规范.md) 为准。本文件记录当前产品上下文，不另设范围或验收结论；最新实现与验证边界见 [07 一期实现与验收](../../docs/07-一期实现与验收.md)。

六个入口固定为：

- **关注**：提交目标，查看 T 组、待审阅草案和运行。
- **Agents**：配置三角色模型与补充要求，按项目派活，查看运行与交付证据。
- **任务**：读取外部执行与任务，使用列表/看板和任务详情线程；创建、修改、状态流转和工时先形成草案。
- **观察**：从持久化运行汇总当前项目的执行、需处理事项及模型消耗；人员负载与空档缺少容量依据时显示待评估。
- **连接**：查看业务连接与执行身份，绑定本人可见项目，显式授予或撤销成员项目读写权限。
- **能力**：安装文本资源技能包并管理固定来源、版本、启停与绑定；配置外部 MCP Server、本人凭据、无业务副作用的连接测试、逐工具分类授权和调用记录。

身份继承协作账号，不建立密码库，也不提供免登录身份。外部协作系统是项目、任务、状态和工时的事实源；Tandem 保存线程、草案、运行、文档与产物等自有资产。空间成员和 T 组初始化不自动授予项目权限。普通产品流程使用统一业务名称，下游专名仅在连接管理等必要上下文中呈现。

外部写入、工具写调用与部署使用统一草案服务。批准绑定内容版本、原执行身份及目标；修改后重新审阅，审批人不能替换执行身份提权。已批准、执行中、成功、失败与结果未知分别显示，只有成功回执能证明外部动作完成。取消只阻止后续执行，不能表示撤销已发生的动作。

运行通过独立 Worker、持久队列、预算和检查点推进；暂停释放容量，续跑继承目标、上下文及累计预算。Skills 与工具版本随运行固定，停用或撤权阻止后续使用。页面与 API 共用 Next.js 主服务；代码、测试和构建通过隔离执行器运行。

**当前边界（2026-11-13）**：本机 Web/Worker 双进程的真实账号、标准迭代项目任务读写、草案、工时、Skills 管理和 MCP 调用链路已验证。模型服务仍未配置，三角色真实推理、运行内技能使用和模型生成 Demo 至部署/回滚的完整链路待验收。执行器支持自包含 Web Demo 与本地演示发布；生产发布适配器尚未实现。现有 Compose 的工程验证不能替代完整业务部署验收。知识检索、Skills 自主积累、完整沙箱管理及高级负载推荐属于后续版本。

## Accessibility & Inclusion

以紧凑蓝白 Operate 工具界面支持日常操作：常驻标签、键盘操作、可读焦点、窄屏和错误恢复；状态同时提供文字。任务、运行、草案和产物分别建模，不用未知零值或预置成功记录填补空态。

任务线程、任务/工时草案、技能、工具服务和团队配置保留未保存内容；关闭或应用内切换前明确选择继续编辑或放弃，刷新离开使用浏览器原生提示。切换范围、会话失效或撤权后清除旧范围数据。当前定向桌面/手机表单与导航复验通过；空间切换的未保存保护已接入，因只有一个授权空间尚未实测，不能从其他导航结论外推。
