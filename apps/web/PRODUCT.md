# Tandem

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

同时推进多个项目的团队负责人、销售、策划、项目经理、研发、运营、学术及其他成员。人员和 Agent 共同参与项目，负责人需要明确目标、日期、任务与资源投入。

## Product Purpose

用简单的项目、文档、任务和资源时间轴组织团队工作；Agent 作为可配置的协作成员提供能力。默认 T 组三角色保持可恢复执行和草案审批。普通用户通过熟悉的表格、分组、文档和任务表单上手。

## Capabilities and Constraints

2026-11-14 用户重新定义产品，以 docs/08-产品重构与验收.md 为新增范围的当前依据，覆盖旧版六入口和仅外部事实源的限制。七个入口：项目、文档、任务、分析、Agents、连接器、后台管理。

本地项目和任务由 Tandem 管理；禅道项目和任务仍由外部系统维护，独立入口实时读取，外部写入经过草案审批。禁止默默把外部记录复制成本地事实或绕过用户授权。

文档统一建模为项目、团队、个人三个空间。个人与私有文档只允许所有者访问；项目/团队共享仍受所属范围权限控制。正文为 Markdown，附件独立保存到 data/attachments，经认证接口下载。RAG 索引与语义检索尚未作为已完成功能。

项目阶段、任务状态、运行、草案与产物分别展示。计划未知显示未设置，实际工时只汇总填报；资源图注明工作日分摊、参考容量与节假日未计入，不将参考分摊宣称精确可用性或自动推荐。

配置与执行分开：沙箱模板注册不等于实例启动，自定义 Agent 注册不等于已接入默认 T 组执行，插件先提供注册扩展点。生产发布仍需部署适配、审批、健康检查和回滚证据。

身份仍继承已有协作账号。新数据存 PostgreSQL，业务通过共享应用服务和逐资源授权访问；Web/API 同进程，Worker 独立，代码与脚本在隔离环境运行。

## Brand Commitments

用户明确指定蓝色主题，拒绝上一版 logo 与视觉。采用深蓝导航与白色工作区、几何 T 标志，重点是简洁、易用、易上手。界面不用营销式大数字或无依据的演示记录。

## Accessibility & Inclusion

常驻标签、键盘焦点、窄屏导航、局部表格滚动、未保存保护、就地错误恢复。管理权限及项目权限同时参与操作判定；权限变化须在服务端即时生效，菜单隐藏不作为安全边界。
