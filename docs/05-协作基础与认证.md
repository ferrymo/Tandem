# 协作基础与认证

## 1. 当前范围

已实现：继承协作账号登录、可撤销会话、创建/切换工作空间、成员权限、事务内初始化 T 组三人、六入口工作台。基础服务检查页在 `/health`。

T 组显示真实身份、职责、挂靠人与模板版本，并已接入项目授权、任务读取、版本草案、运行编排、Skills/MCP 管理及隔离执行。本文聚焦身份与空间基础；本机真实模型 Demo、获批本地发布及后续回滚的结果集中记录于 [07 一期实现与验收](07-一期实现与验收.md)。生产发布适配器尚未实现。

## 2. 本地配置

先执行 `pnpm local:init`、`pnpm db:migrate`。在被忽略的 `.env` 中设置：

```dotenv
TANDEM_PUBLIC_URL=http://127.0.0.1:3000
TANDEM_IDENTITY_URL=https://collaboration.example.com/
TANDEM_IDENTITY_ID=primary
TANDEM_IDENTITY_LABEL=协作系统
TANDEM_COMMANDER_ACCOUNTS=zhangsan
TANDEM_IDENTITY_ALLOW_HTTP=false
```

- 首个认证适配器为禅道 REST v1。地址可为站点根或以 `/api.php/v1` 结尾；配置固定在部署端，浏览器不能指定目标地址。
- `TANDEM_COMMANDER_ACCOUNTS` 是精确账号白名单，以逗号分隔。为空时无人可创建空间；不凭未知角色名称猜测负责人。普通用户由空间所有者添加成员。
- `SESSION_ENCRYPTION_KEY` 由初始化生成，须备份并保护；更换后旧会话无法解密，需要重新登录。密码只传给身份提供方，不写数据库或日志。
- 默认要求 HTTPS。可信本机/内网 HTTP 站点需显式设置 `TANDEM_IDENTITY_ALLOW_HTTP=true`；正式入口使用 HTTPS，并使公共地址与浏览器来源一致。通过 `localhost` 或其他端口访问时同步修改公共地址。
- 修改身份配置后重启 Web 和 Worker，保持两者使用同一身份实例和会话密钥。未配置身份地址时保留可恢复的引导页，不提供免登录或样例身份。
- 身份键包含连接标识与规范化站点地址指纹。更换站点不会继承另一个实例的同号用户及其空间权限；同站点地址迁移须显式处理身份映射。

本机已配置 Docker 禅道开源版 22.7，地址为 `http://127.0.0.1:8088/`，连接标识为 `local-zentao`，指挥官账号为 `admin`。部署、配置与真实站点检查见 [06 本地禅道接入](06-本地禅道接入.md)；账号密码只保存在被忽略的本地凭据文件。

登录后，指挥官创建空间时会同时建立 Owner 成员、T 组和产品设计师/技术架构师/研发工程师。重复提交使用同一个请求标识；同标识不同内容返回冲突，不重复建组或覆盖配置。

添加成员前，对方须先登录一次，再从“我的账号”提供成员 ID。Owner 可添加 Admin/Member；Admin 仅管理 Member；Member 可查看成员列表，不能管理成员。Owner 不可被降级或删除，成员变更在数据库中串行校验。

空间成员资格不等于项目授权。在“连接”绑定项目并显式授予成员及 T 组挂靠人读/写权限；外部访问仍使用本人账号，并重新核验上游权限。运行与能力调用同时受发起人、挂靠人及项目范围限制，审批人不能替换执行身份提权。细则见 [07](07-一期实现与验收.md#3-使用与权限)。

## 3. 安全与 API

Tandem 会话为 8 小时不透明随机令牌，数据库只保存 SHA-256 摘要；上游令牌使用 AES-256-GCM 加密并绑定身份。Cookie 为 HttpOnly、SameSite=Strict，HTTPS 下使用 Secure 与 `__Host-` 前缀。写请求必须来自配置的同源地址。

每次业务请求重新核验上游身份、本地会话和当前空间成员资格；上游明确拒绝时撤销会话，暂不可用时返回 503。退出会撤销本地会话并清除密文，重放旧 Cookie 无效。前端定时及窗口重新可见时复核会话，失效后清除敏感视图。

本期为单 Web 进程，登录限制同时约束全局、单账号和并发请求，不信任客户端转发头。多实例部署前须改为共享限流；数据库会话撤销和成员权限已跨进程生效。

| API                                              | 用途                                       |
| ------------------------------------------------ | ------------------------------------------ |
| `GET/POST/DELETE /api/session`                   | 会话检查、登录、退出                       |
| `GET/POST /api/workspaces`                       | 有权空间列表、幂等创建                     |
| `GET /api/workspaces/:id`                        | 空间与 T 组                                |
| `GET/POST /api/workspaces/:id/members`           | 成员列表、添加/变更角色                    |
| `DELETE /api/workspaces/:id/members/:identityId` | 移除成员                                   |
| `GET /api/connection`                            | 当前身份连接与账号授权，不代表项目读取授权 |

项目、草案、运行和能力使用 `/api/workspaces/:id/product`，产物使用 `/api/workspaces/:id/artifacts/:runId/...`；均继承有效会话并逐资源授权，详见 [07 的 API 说明](07-一期实现与验收.md#5-产品-api-与对外-mcp)。

所有接口使用无缓存响应与请求 ID；身份与凭证密文不进入客户端响应。应用服务不依赖 Next.js；数据库函数限制入口与角色，RLS 同时校验空间和成员，Worker 没有业务表跨空间权限。

## 4. 验证

```bash
pnpm check
pnpm test:integration
pnpm build
pnpm test:collaboration
pnpm exec playwright install chromium
pnpm test:collaboration:browser
# 启动主服务后
pnpm test:e2e
# 本机禅道与 Tandem 均已启动，并已配置本地验收凭据
pnpm test:zentao
```

数据库集成覆盖会话摘要/撤销/过期、并发幂等初始化、三人角色、配置保留、成员权限、跨空间/身份隔离及故障回滚。HTTP 回归启动独立测试库和测试协作服务，验证生产构建的认证、Origin、幂等、成员授权和撤销链路；替身只存在于测试脚本，不成为产品登录方式。

`test:collaboration:browser` 追加通过真实 API 登录、创建空间、T 组三人、成员对话框与桌面/窄屏布局的浏览器检查，截图存入 Git 忽略的 `.impeccable/review/`。

真实协作系统的版本兼容、账号策略与网络连通性须在实际站点验证；测试服务通过不能替代这项验收。本机禅道 22.7 已完成 REST 身份验证与浏览器登录，详见 [06 的验收记录](06-本地禅道接入.md#验收记录)。后续接入的外部项目授权、任务草案和可恢复运行，另见 [07 的验证与证据](07-一期实现与验收.md#6-验证与证据)。

认证基础已通过真实 PG、生产 HTTP 和浏览器回归，覆盖同账号登录、空间与 T 组幂等初始化、成员变更及即时撤权。备份隔离恢复通过；重建本机协作系统容器并重启主服务后，原会话、空间与 T 组身份仍保留。当前业务回归数量、结果与未验收项统一记录在 [07](07-一期实现与验收.md#6-验证与证据)。
