### 2. 已实现功能（全部实测通过）

#### 多项目协作（v0.9 继承）

- ✅ **工作台**：KPI 统计 + 项目进展卡片 + 团队负载排行 + 我的今日侧栏（工时环/三日到期）
- ✅ **任务**：跨项目看板 ⇄ 列表双视图；状态流转（开始/暂停/完成带工时/关闭）；⌘K 全局命令面板
- ✅ **工时**：跨项目一屏批量填报直写禅道（recordWorkhour 数组格式实测落库）；时间轴（人员×日期热力，周/月/自定义）；统计（按人/项目/周期）
- ✅ **排期**：人员甘特 + 空档速览；状态驱动配色、逾期斜纹、按空档/负载排序

#### 组织管理（权限地基）

- ✅ **项目分组树**：多级分组、防环移动、项目映射入组、隐藏开关——**分组即数据权限边界**（viewers 白名单）
- ✅ **团队管理**：成员 = 人 + Agent 同表混编（Worker 统一模型）
- ✅ **Agents 管理**：角色模板（planner/executor/tester/recorder/watcher）、能力标签、skills 配备、挂靠人=权限上界、模型配置、**RAG 预留位**
- ✅ 存储：SQLite（node-sqlite3-wasm，免编译跨平台）——Tandem 自有资产，下游数据零复制

#### 人机协作机制（v2.1 核心，已闭环验证）

- ✅ **统一连接器端口**（`CollabAdapter`）：读/写/能力声明；禅道适配器首个实现；Agent 工具不感知下游
- ✅ **草案引擎**：`propose → check → review → execute` 三段式；人/Agent/MCP 三端共用；**一切写操作先成草案，人批准才落库**
- ✅ **AgentRunner**：目标循环器（取上下文→思考→调工具→观察）；OpenAI 兼容 LLM；安全阀 = 步数预算 / 写必草案 / `ask_human` 暂停待人决策 / 停止词
- ✅ **Agent 运行台**（`/runs`）：目标发起 → 步骤流（思考/工具/结果分类）→ 草案审批 → 决策答复续跑
- ✅ **zentao-mcp**：10 工具 stdio MCP Server（外部 AI 客户端入口，草案确认模式），冒烟 9/10

#### 基础设施

- ✅ 会话按人代理（权限=本人）、TTL 聚合缓存、Fastify + Next.js 16 + antd 6 全链路
- ✅ 已知平台坑防御内建（21.7.9：recordWorkhour 数组格式 / DELETE 空操作 / estStarted 必填 / 强制改密优雅降级）
- ✅ 验证脚本：`verify-effort.ts` / `verify-full.ts` / `mcp-smoke.mjs` / `mock-llm.mjs`（无 LLM 也可演示机制）
