## 数据和安全

- 新增业务走 core/application/storage-postgres 三层，通过 Web server 组装。新表前缀 wm_；迁移从0010开始追加，不改写已执行迁移。
- 工作空间、项目、团队和个人权限在应用与 PG RLS 同时限制；角色权限不能越过项目 ACL，角色不等同于 workspace owner/admin。禁用已分配角色不会回退到默认权限。
- 文档正文、任务时间轴和工时均持久化。编辑携带版本；批量工时事务提交，以请求ID保证重试幂等，并限制同人同日合计24小时。历史/工时/文档版本对运行账号只追加。
- 附件位于独立 data/attachments（可配置绝对目录），元数据入PG；随机存储键、20MB上限、路径约束、授权下载、禁用嗅探，不向页面返回宿主路径。
- 模型和连接器凭据单独加密存储，界面不回显；模型请求失败不把私密响应写入日志。凭据保存与配置保存分开，失败保留当前输入以重试。

## 统计口径

资源计划按执行人在计划起止日之间的工作日平均分摊；协助人不自动重复计算。实际工时按填报人、任务和工作日归属。容量为手工参考值，不包含法定节假日和请假；Agent 工时不与人的日容量混算。一次最多显示31天。缺少排期、工时或执行人的任务单独列出，不能默认为零负载。

燃尽按任务创建与状态变更记录重建剩余任务数，保留完成、重新打开、再次完成和取消的历史变化；无状态事件的旧记录才使用实际完成日期作为回退。虚线是参考趋势，不声称具有历史每日快照。

## 管理流程与权限边界

- Agent 卡片支持按名称、职责及启停状态筛选。所选模型渠道决定协议与可选模型，避免注册配置互相矛盾；自定义 Bot 的配置保存不表示已执行。
- 人员使用真实协作身份加入空间，可调整成员角色或移出空间。项目授权从当前空间人员中选择；外部项目授权仍受本人禅道权限约束，不能以管理员身份代替执行者。
- 自定义角色支持分配给成员。未分配角色的成员保留默认协作权限；分配后取所有启用角色的权限并集，停用角色不会恢复默认权限。`config.manage` 可维护渠道等元数据；模型密钥与模型连接测试仅供空间管理员操作。禅道只读授权绑定提交授权的本人，不使用其他成员或全局凭据兜底。
- 模型 API Key 和连接器密码与元数据分开保存，编辑不回显。凭据失败后保留输入，重试只提交未完成的凭据步骤，避免重复创建配置。模型测试使用界面保存的渠道密钥，不从任意环境变量读取或转发全局密钥。
- 禅道只读数据库授权按当前用户、连接器及配置版本加密隔离，结合本人禅道 API 可见项目和精确任务权限过滤读取。测试核验数据库账号仅有读权限并使用只读事务；读取按需触发，保留来源与有效期，不复制业务表。仅改凭据不递增配置版本，留空保留本人原值；连接配置变更须重授，旧验证与读取结果立即失效。
- 默认 T 组的角色模型可选择已保存渠道，也可使用部署默认模型。选择绑定渠道、配置版本及模型名称；Worker 每步重新核验版本、启停及运行授权。OpenAI 兼容、Anthropic 与 Ollama 协议已通过隔离服务验证，不等于所有真实上游兼容性均已验收。
- Skills 安装、版本切换、启停与卸载沿用真实能力服务；MCP 工具来自连接发现，逐项目与角色分类授权。未知副作用分类不能直接执行，写工具进入草案，移除服务或撤权阻止后续调用。
- 沙箱提供镜像、目录、网络、CPU 与内存配置及启停登记，删除受引用约束；该登记不声称容器实例已启动。插件提供固定版本登记，不执行第三方代码。

## 明确边界

- RAG 目前准备了空间/可见性/版本模型，尚未实现检索与问答。
- 自定义 Agent 卡片与沙箱模板是可持久管理的配置；任意自定义 Bot 执行和沙箱实例创建/启停/回收尚未接通。默认三角色T组仍通过已有Worker运行和草案服务执行。
- 项目仓库与部署目标、分支和命令可维护，尚未消费这些配置建立自动部署流水线；已有T组交付使用原草案审批与隔离执行链路。
- 插件管理提供固定来源、版本和启停注册，尚未加载第三方可执行插件；符合用户“后续开放部分能力”的阶段目标。
- 禅道保留原项目任务、草案写入与工时链路；新增数据库接入提供按需只读验证与读取，不是后台全量同步。已通过隔离 PG、真实 MySQL 8.4 及本机禅道 HTTP 替身验证；未访问客户站点或数据库，实际账号兼容性仍需验收。
- 生产环境发布适配、外部服务/真实模型上游、实际读屏器及完整假期容量仍需独立验收。
